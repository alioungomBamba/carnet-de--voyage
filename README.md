Le projet "Carnet de voyage : Dakar" est un site web multipage, moderne et interactif, conçu pour faire découvrir la capitale du Sénégal, sa culture, son histoire et sa célèbre Téranga (l'hospitalité sénégalaise).

Ce projet a été développé dans le cadre d'un apprentissage approfondi du développement web (HTML5, CSS3 et JavaScript), respectant les normes de sémantique, d'accessibilité et de validation W3C.
